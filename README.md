# CarCare

A mobile-first web app for personal drivers and small rental fleet owners to track vehicle maintenance, log service history, compare shop options, and get service reminders.

## Project Structure

```
/client/     # React PWA (local dev: Vite)
/api/        # Express API (local dev: Node)
/supabase/   # SQL migrations + seeds
/docs/       # PRD, site map, OpenAPI, deployment notes
```

## Tech Stack

- **Client**: React PWA with Vite
- **API**: Express.js
- **Database**: Supabase (PostgreSQL)
